# CS ソースコードコンパイル読み込みモード デモ

プリコンパイル済み DLL ではなく、生の `.cs` ソースファイルから読み込まれるプラグイン。PluginLoader の CS ソースコンパイルモード（task-389 で導入）をデモンストレーションします。

## CS ソースモードの仕組み

PluginLoader がプラグインディレクトリをスキャンし、**DLL が見つからない**場合、自動的に CS ソースモードに入ります：

```
1. PluginLoader がプラグインディレクトリをスキャン → DLL なし
2. CS ソースモードに入る
3. cs.txt 発見 → 行ごとに読み込み、リストされた .cs ファイルのみ読み込む
   （cs.txt なし → ディレクトリ内のすべての *.cs ファイルを読み込む）
4. 同階層 DLL をスキャン → 信頼済み DLL は直接参照として追加；
   非信頼 DLL は ScanForbiddenReferences セキュリティスキャンを通過する必要あり
5. CompilationCore（制限モード）が .cs ファイルをメモリ内 DLL にコンパイル
6. メモリ内 DLL バイトを一時ファイルに書き込み、ScanForbiddenReferences スキャンを実行
7. スキャン通過 → リフレクションで IPlugin 実装を検索 → インスタンス化
8. ログ表示："Plugin loaded [CS-Source]: {Id} v{Version} from {DirName}"
```

## cs.txt — 選択的読み込みホワイトリスト

`cs.txt` ファイルはコンパイルする `.cs` ファイルを指定します。1行に1ファイル名：

```
Plugin.cs
```

- **リストされたファイル**：コンパイル・読み込みされる（例：`Plugin.cs`）
- **リストされていないファイル**：コンパイラに無視される（例：`Helpers.cs`）
- **`#` で始まる行**：コメントとして扱われる
- **空行**：無視される
- **cs.txt なし**：ディレクトリ内のすべての `*.cs` ファイルが読み込まれる

このデモでは意図的に cs.txt に `Plugin.cs` のみをリストしています。`Helpers.cs` はディレクトリに存在しますがコンパイルに**参加しません**。選択的読み込み機構のデモンストレーションです。

## ディレクトリ構造

```
22-CSSourceMode/
├── Plugin.cs          — IPlugin 実装（cs.txt にリスト → コンパイルされる）
├── Helpers.cs         — ヘルパークラス（cs.txt になし → コンパイルされない）
├── cs.txt             — コンパイルする .cs ファイルを指定するホワイトリスト
├── README.md          — 英語ドキュメント
├── README.ja-JP.md    — 日本語ドキュメント
└── ...                — その他の言語 README
```

## CS ソースモード vs DLL モード

| 側面 | DLL モード | CS ソースモード |
|------|-----------|----------------|
| プラグイン形式 | プリコンパイル済み `.dll` | 生の `.cs` ソースファイル |
| 読み込みトリガー | プラグインディレクトリに DLL が見つかる | DLL なし、`.cs` ファイルが存在 |
| コンパイル | ビルド時に実行 | 読み込み時に PluginLoader が実行 |
| パフォーマンス | コンパイルオーバーヘッドなし | 起動時に Roslyn コンパイルオーバーヘッド |
| セキュリティスキャン | 直接 PE メタデータスキャン | コンパイル → 一時 DLL → PE メタデータスキャン |
| ログプレフィックス | `Plugin loaded:` | `Plugin loaded [CS-Source]:` |
| 最適な用途 | 本番デプロイ | 開発イテレーション |

## エラー処理

| シナリオ | 動作 |
|----------|------|
| DLL も .cs ファイルもなし | 警告："No DLL and no CS source files found" |
| コンパイルエラー | エラー：詳細な診断メッセージをログ記録 |
| セキュリティスキャン失敗 | エラー：すべての違反をリスト、プラグイン拒否 |
| cs.txt エントリが見つからない | 警告："cs.txt entry not found or not a .cs file" |
| 同階層 DLL スキャン失敗 | 警告：DLL は参照として追加されず、コンパイル続行 |

## セキュリティに関する注意

CS ソースモードのプラグインは、DLL モードのプラグインと**同じセキュリティスキャン**を受けます。コンパイルされたアセンブリは一時 DLL ファイルに書き込まれ、`ScanForbiddenReferences` でスキャンされます。これはプリコンパイル済み DLL が受けるスキャンと同じです。禁止された名前空間/型/メンバー/文字列ルールがすべて同様に適用されます。

プラグインは引き続き分離されたコンテキストで読み込まれ、禁止された名前空間参照（例：`System.IO`、`System.Net.Http`）がスキャンされます。詳細は[セキュリティドキュメント](../../docs/ja-JP/security.md)を参照してください。
