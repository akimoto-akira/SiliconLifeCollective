# PluginDemo-08: Анти-паттерн Запрещённых Сетевых Операций

## Обзор

Этот плагин демонстрирует **ЗАПРЕЩЁННЫЕ** сетевые операции в системе плагинов SiliconLife. Он служит справочником анти-паттернов, показывая, что НЕЛЬЗЯ делать, и предоставляя правильные альтернативы.

## Почему прямой сетевой доступ глобально запрещён?

Паттерны прямого сетевого доступа заблокированы на уровне плагинов:

1. **Подключение к вредоносным серверам**: Плагины могут подключаться к вредоносным серверам
2. **Эксфильтрация данных**: Плагины могут выводить конфиденциальные данные из песочницы
3. **Атаки DNS Rebinding**: Плагины могут обходить проверки безопасности
4. **Обход сетевого ACL**: Прямой сетевой доступ обходит глобальную систему ACL

## Запрещённые типы

Все типы `System.Net`, напрямую обращающиеся к сети, заблокированы:

| Запрещённый тип | Заблокированное пространство имён | Уровень риска |
|----------|----------------|----------|
| `HttpClient` | `System.Net.Http` | 🔴 Критический |
| `TcpClient` | `System.Net.Sockets` | 🔴 Критический |
| `Socket` | `System.Net.Sockets` | 🔴 Критический |
| `Dns` | `System.Net` | 🔴 Критический |
| `WebClient` | `System.Net` | 🔴 Критический |

## Безопасные методы доступа

### NetworkExecutor (Рекомендуется)

`NetworkExecutor` — это **контролируемая точка входа** для сетевых операций:

```csharp
// ✅ ПРАВИЛЬНО: Простой GET-запрос
var result = NetworkExecutor.Execute(new ExecutorRequest
{
    ResourcePath = "https://api.example.com/data"
});
```

**Что предоставляет NetworkExecutor:**
1. Проверка разрешений
2. Журналирование аудита
3. Автоматический выключатель
4. Контроль тайм-аута
5. Очередь запросов

## Продемонстрированные нарушения

### Нарушение 1: HttpClient

```csharp
// ❌ ЗАПРЕЩЕНО
using var client = new HttpClient();

var result = NetworkExecutor.Execute(new ExecutorRequest
{
    ResourcePath = "https://api.example.com"
```

```csharp
// ❌ ЗАПРЕЩЕНО
using var client = new TcpClient("example.com", 8080);
```

## Механизм безопасности PluginLoader

PluginLoader сканирует этот плагин и:
1. **Сканирование TypeRef**: Обнаруживает ссылки на запрещённые типы
2. **Сканирование MemberRef**: Обнаруживает вызовы заблокированных методов
3. **Сканирование строк IL**: Обнаруживает попытки отражения
4. **Отклонение**: Плагин отклоняется при загрузке
