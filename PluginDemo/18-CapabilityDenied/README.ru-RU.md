# PluginDemo-18: Возможность отклонена — Антипаттерн недекларируемой возможности

## Обзор

Этот плагин — **антипаттерн**, демонстрирующий, что декларация возможности НЕ обходит запреты недекларируемых возможностей. Даже с `[PluginCapability(Capability.Network)]`, P/Invoke, Unsafe, Reflection.Emit и доступ к реестру остаются **всегда** заблокированными.

## Декларируемые vs. недекларируемые возможности

### ✅ Декларируемые (значения перечисления Capability существуют)

| Возможность | Что освобождает |
|-----------|----------------|
| `Capability.Network` | Пространства имён System.Net.* и запреты на уровне типов |
| `Capability.FileIO` | Пространство имён System.IO (за пределами белого списка) |
| `Capability.Process` | Типы Process* под System.Diagnostics |
| `Capability.AI` | Включает внедрение IAIService (без освобождения TypeRef) |

### ❌ Недекларируемые (НЕТ значения перечисления Capability)

| Категория | Заблокированные типы | Почему недекларируемые |
|----------|---------------------|----------------------|
| P/Invoke | `DllImportAttribute`, `Marshal`, `NativeMemory`, `NativeLibrary` | Невозможно аудировать произвольный нативный код во время выполнения |
| Небезопасный код | `UnverifiableCodeAttribute`, `System.Runtime.CompilerServices.Unsafe` | Обходит безопасность типов CLR и проверки границ |
| IL-генерация | `System.Reflection.Emit.*` | Может генерировать произвольный IL во время выполнения |
| Загрузка сборок | `System.Runtime.Loader`, `Assembly.Load*` | Может загружать непроверенные DLL, обходя сканирование безопасности |
| Реестр | `Microsoft.Win32.*` | Доступ к системе на уровне ОС вне песочницы плагина |
| Динамическая компиляция | `Microsoft.CodeAnalysis.*` | Может компилировать и выполнять произвольный код |
| Опасная рефлексия | `Type.GetType(string)`, `Activator.CreateInstance` | Может создавать экземпляры запрещённых типов по строке |

## Почему эти возможности недекларируемы

Фундаментальная причина: **их невозможно безопасно аудировать во время выполнения.**

1. **P/Invoke**: Как только вызван нативный код, CLR не имеет видимости — никаких гарантий безопасности
2. **Unsafe**: Обходит систему безопасности типов, на которую опирается модель безопасности плагинов
3. **Reflection.Emit**: Может генерировать новый IL во время выполнения, никогда не сканированный PluginLoader
4. **AssemblyLoadContext**: Может загружать DLL, никогда не проверенные на безопасность
5. **Registry**: Предоставляет доступ к конфигурации на уровне ОС вне песочницы плагина

## Обработка «недействительной декларации» PluginLoader

Когда PluginLoader встречает декларацию возможности:

1. Читает значение перечисления int32 из blob CustomAttribute
2. Проверяет `Enum.IsDefined(typeof(Capability), value)`
3. Если значение не является определённым членом Capability → **тихо игнорируется**
4. Если значение определено → применяются правила освобождения
5. **Проверки недекларируемых возможностей ВСЕГДА применяются** независимо от любых декларированных возможностей

Это предотвращает декларацию плагинами «будущих» возможностей, которые ещё не существуют.
