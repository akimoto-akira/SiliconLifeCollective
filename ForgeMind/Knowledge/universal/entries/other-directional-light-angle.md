# 定向光源源角度：太阳的视面积

## 适用场景

调整定向光源（DirectionalLight）时，需要理解源角度对阴影柔和度的影响。

## 核心概念

**源角度（lightSourceAngle）** 表示光源的视面积大小。如果把天空穹顶理解为 180°，源角度就是太阳在天空中占据的角度。

| 参数 | 含义 |
|---|---|
| 天空穹顶 | 180°（整个半球） |
| 太阳视角度 | 约 0.5357°（真实值） |
| UE 默认值 | 0.7357 弧度 ≈ 42.2° |

## UE 中的设定

UE 中默认源角度为 **0.7357 弧度（约 42.2°）**，远大于真实太阳的 0.53°。这是为了让阴影边缘更柔和，避免游戏画面中阴影过硬。

## 操作建议

- **角度越大** → 阴影边缘越软（soft shadow）
- **角度越小** → 阴影边缘越硬（sharp shadow）
- 调整时配合阴影级联数（Cascades）使用

## 注意事项

1. 真实太阳视角度约 0.53°，UE 默认值 42.2° 是艺术化处理。
2. 源角度与强度（lux）独立控制，互不影响。
3. 过大的源角度会导致阴影模糊过度，失去立体感。
