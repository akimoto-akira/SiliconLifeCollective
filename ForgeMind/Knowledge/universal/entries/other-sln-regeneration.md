# 解决方案文件不一致或缺失时重新生成 .sln

## 适用场景

1. **外部 IDE 与磁盘文件不同步**：Visual Studio 或 Rider 打开项目时，发现解决方案中的文件列表与实际磁盘上的源文件不一致（如新增/删除/重命名文件后 IDE 未感知）。
2. **项目没有 .sln 文件**：UE C++ 项目在某些情况下（如手动创建、从源码拉取、引擎升级后）缺少 `.sln` 解决方案文件，导致无法用 IDE 正常打开项目。

## 解决方法

调用 `unreal_sln` 工具重新生成 Visual Studio 解决方案：

```
unreal_sln(path="项目路径或.uproject文件路径")
```

该工具会：
- 扫描项目目录下的 `.Build.cs` 文件和源文件
- 重新生成与引擎版本匹配的 `.sln` 和 `.vcxproj` 文件
- 覆盖旧的解决方案文件，确保与磁盘文件一致

## 注意事项

1. **不要手动编辑 .sln**：手动修改容易引入格式错误，且引擎升级后会被覆盖。
2. **先关闭 IDE**：生成前关闭 Visual Studio/Rider，避免文件锁定冲突。
3. **生成后重新打开**：完成后再用 IDE 打开项目，确保加载新生成的解决方案。
4. **仅用于 UE 项目**：该工具专为 Unreal Engine 项目设计，非 UE 项目可能不适用。
