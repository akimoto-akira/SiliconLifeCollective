## 概述

Web UI 提供了一個全面的介面，用於管理矽基生命體、監控系統狀態和與 AI 智能體互動。系統採用純服務端渲染架構，零前端框架依賴，透過 `H`、`CssBuilder` 和 `JsBuilder` 建構器生成 HTML、CSS 和 JavaScript。

## 存取

預設 URL：`http://localhost:8080`

## 導覽

### 主要部分

1. **儀表板** - 系統概覽和指標
2. **生命體** - 管理矽基生命體（含技能管理、AI 設定、靈魂檔案）
3. **聊天** - 與生命體互動（支援檔案上傳、即時 SSE）
4. **聊天歷史** - 檢視矽基生命體的聊天歷史記錄（會話清單、訊息詳情）
5. **任務** - 任務管理（個人任務）
6. **定時器** - 定時器設定（建立、暫停、執行歷史）
7. **設定** - 系統設定（AI 用戶端、IM 平台多實例、MCP 伺服器、在地化）
8. **權限** - 存取控制（ACL 管理、權限查詢、工具動作權限）
9. **日誌** - 系統日誌（按等級過濾、時間範圍查詢）
10. **審計** - Token 使用和審計追蹤
11. **記憶** - 生命體記憶（時間線檢視、進階過濾）
12. **知識** - 知識庫（三元組管理、路徑發現）
13. **程式碼瀏覽器** - 程式碼探索（檔案樹、語法高亮）
14. **程式碼編輯器** - 帶懸浮提示的程式碼編輯（Monaco Editor）
15. **專案** - 專案管理（工作區、任務、工作筆記）
16. **執行器** - 執行器管理（磁碟、網路、命令列）
17. **MCP** - MCP 伺服器管理（新增、啟停、重連、測試）
18. **幫助** - 說明文件系統（多語言支援、主題搜尋）
19. **關於** - 系統資訊和版本

## 設定

### AI 用戶端

設定 AI 後端（13 種用戶端）：
- Ollama（本地）
- 阿里雲百煉 DashScope（雲端）
- 字節火山引擎 Ark（雲端）
- 牧馬人推理引擎 Herdsman（本地/雲端，無需認證）
- 美團 LongCat（雲端）
- 七牛雲 AI（雲端）
- DeepSeek（雲端）
- 智譜 GLM（雲端）
- 月之暗面 Kimi（雲端）
- 矽基流動 SiliconFlow（雲端）
- MiniMax（雲端）
- 百度千帆 ERNIE（雲端）
- 騰訊混元（雲端）

每個用戶端的設定表單由各用戶端工廠動態提供（API 金鑰、端點、模型下拉清單等），並有對應的說明文件（可在設定頁直接跳轉）。

### IM 平台（多實例）

IM 平台設定支援多實例架構，可同時啟用多個平台：

1. 點擊**新增平台**，選擇平台類型：
   - **Web UI**（內建，預設啟用）
   - **飛書**（支援手動設定和 OAuth 一鍵授權）
   - **企業微信**（手動設定）
   - **釘釘**（手動設定，支援 Stream / HTTP 兩種事件模式）
2. 按動態表單填寫平台欄位（必填項帶星號，金鑰欄位為密碼框）
3. 每個實例可獨立啟用/停用、刪除

**金鑰環境變數**：設定值支援 `${ENV_VAR}` 佔位符（如 `"${FEISHU_APP_SECRET}"`），執行時從環境變數解析，明文金鑰不會寫入 config.json。

**OAuth 授權精靈**（飛書）：儲存 appId/appSecret 後，設定頁出現行內授權區，點擊**授權**按鈕會開啟系統瀏覽器跳轉飛書授權頁；完成授權後令牌自動寫回設定，頁面透過 SSE 即時顯示授權狀態（成功/失敗/逾時），無需手動複製貼上。

### MCP 伺服器

MCP 伺服器清單在設定頁中集中管理（陣列編輯器）：每行一個伺服器（ID、名稱、傳輸方式 stdio/http、命令或端點、啟用狀態），支援行內**新增**和**刪除**。儲存後伺服器立即連線，其工具自動注入到矽基生命體。詳見下文 [MCP 管理](#mcp-管理) 章節。

### 儲存設定

- Default 版本：基礎路徑、時間索引、清理策略
- Fast 版本：SpeedyPack 儲存引擎設定、.spk 檔案管理、自動壓縮設定

### 在地化

在 34 種語言變體之間切換：
- 中文（6 種）：簡體中文、繁體中文、新加坡中文、澳門中文、台灣中文、馬來西亞中文
- 英文（10 種）：美式、英式、加拿大、澳洲、印度、新加坡、南非、愛爾蘭、紐西蘭、馬來西亞英語
- 西班牙語（2 種）：西班牙、墨西哥
- 德語（5 種）：德國、奧地利、瑞士、盧森堡、列支敦斯登
- 法語（3 種）：法國、加拿大、瑞士
- 日語、韓語、捷克語
- 俄語、葡萄牙語（2 種）、義大利語、荷蘭語、波蘭語、瑞典語

1. 點擊**設定**（齒輪圖示）
2. 選擇**佈景主題**
3. 選擇所需佈景主題
4. 介面立即更新

### 自訂佈景主題

透過實作 `ISkin` 建立自訂佈景主題：

```csharp
public class MySkin : ISkin
{
    public string Name => "MySkin";
    
    public string GetCss()
    {
        return ":root { --primary: #color; }";
    }
}
```

## 權限管理

### 檢視權限

- 列出所有權限規則
- 按使用者或資源過濾
- 檢視過期日期

### 新增權限規則

1. 點擊**新增規則**
2. 設定：
   - 權限類型（如 `FileAccess`, `NetworkAccess`）
   - 資源前綴（如 `C:\Projects`, `api.github.com`）
   - 允許/拒絕
   - 描述
3. 儲存

### 審計追蹤

檢視所有權限決策：
- 時間戳
- 使用者
- 資源
- 決策
- 原因

### 工具權限管理

管理矽基生命體和專案的工具操作權限：

1. **矽基生命體工具權限**：
   - 導覽到**生命體** → 選擇生命體 → **工具權限**

   - 逐操作設定允許/拒絕

2. **專案工具權限**：
   - 導覽到**專案** → 選擇專案 → **工具權限**

## 專案工作區（新增）

### 功能概述

專案工作區提供了一個結構化的工作環境，支援專案管理、任務追蹤和工作筆記。

### 專案管理

1. **建立專案**：
   - 專案名稱和描述
   - 專案標籤（分類）
   - 專案狀態（進行中、已完成、已歸檔）
2. **檢視專案詳情**：
   - 專案基本資訊
   - 關聯任務清單
   - 工作筆記清單
   - 專案進度統計
3. **歸檔專案**：保留歷史資料但不再活躍
4. **專案角色管理**：
   - 為矽基生命體分配專案角色（如 developer、reviewer、manager）
   - 移除角色分配
   - 檢視專案成員和角色清單
5. **專案工作流**：
   - 檢視工作流範本清單
   - 為專案綁定工作流範本
   - 檢視工作流實例狀態
   - 檢視工作流執行日誌

### 工作筆記（私有）

矽基生命體的個人工作筆記，類似日記本：

1. **建立筆記**：
   - 摘要（簡短描述）
   - 內容（支援 Markdown 格式）
   - 關鍵詞（用於搜尋）
   - 自動時間戳記錄
2. **管理筆記**：
   - 按時間線瀏覽（頁式設計）
   - 搜尋筆記（按關鍵詞、摘要、內容）
   - 生成目錄（快速瀏覽筆記結構）
   - 更新和刪除筆記
3. **權限控制**：
   - 預設私有，僅生命體自身可存取
   - 矽基主理人可管理所有筆記

### 技術實作

- **控制器**：`WorkNoteController`
- **工具**：`WorkNoteTool`、`ProjectTool`、`ProjectWorkNoteTool`
- **API 路由**：
  - `/api/worknotes` - 取得工作筆記清單
  - `/api/worknotes/{id}` - 取得筆記詳情
  - `/api/worknotes/search?q=keyword` - 搜尋筆記
  - `/api/worknotes/directory` - 生成筆記目錄
  - `/api/projects` - 專案管理 API

## 技能管理

### 功能概述

技能（Skill）是「工具編排 + 提示詞範本」的可重用能力單元。技能管理頁面（`/skill?beingId={id}`）為每個矽基生命體提供技能的視覺化管理。

### 頁面佈局

- **左側技能清單**：卡片式展示（標題、`版本 · 來源 · 觸發模式` 徽章、描述）
- **右側編輯器**：Markdown 編輯器（YAML 前置元資料 + 提示詞正文）
- **頂部統計**：技能總數 / 自訂技能數 / 配額上限（如 `5 / 2 / 50`）

### 工具列操作

- **新建**：載入 Markdown 技能範本
- **匯入 .md / 匯入 .json**：從本地檔案匯入技能
- **重新整理**：重新載入技能清單

### 技能卡片操作

每個技能卡片提供 5 個操作：

| 操作 | 說明 |
|------|------|
| 編輯 | 在右側編輯器中開啟 Markdown，可儲存（upsert） |
| 測試 | 輸入參數 JSON，立即執行一次技能並檢視結果 |
| 匯出 JSON | 下載 `{id}.json` |
| 匯出 Markdown | 下載 `{id}.md` |
| 刪除 | 刪除技能（含持久化檔案） |

### 編寫技能

技能以 Markdown 編寫，YAML 前置元資料聲明 id、描述、參數 schema、工具白名單、觸發模式等；正文為提示詞範本（支援 `{param}` 佔位符）。只寫正文（省略 YAML）也可以——儲存時 AI 會自動補全缺失的元資料，且使用者提供的欄位永不被覆蓋。

```markdown
---
id: daily_news_digest
description: 搜尋今日科技新聞並生成摘要
tool_whitelist: [network, work_note]
trigger_mode: Auto
metadata:
  schedule: "0 9 * * *"
---

請使用 network 工具搜尋 {topic} 的最新新聞，生成 500 字摘要並儲存到工作筆記。
```

### 技術實作

- **控制器**：`SkillController`（頁面 + 10 個 API 端點）
- **核心**：`SkillManager`（註冊/執行/熱重載）、`SkillMetadataCompleter`（AI 元資料補全）
- **熱重載**：生命體每 30 秒檢測 `skills/` 目錄變更，Web UI 儲存後無需重啟
- **版本歸檔**：每次更新自動歸檔到 `skills/archive/{id}/{version}.md`

## MCP 管理

### 功能概述

MCP（Model Context Protocol，模型上下文協議）管理頁面（`/mcp`）用於管理外部 MCP 伺服器連線。連線後，伺服器提供的工具會以 `mcp_{伺服器ID}_{工具名}` 的形式自動注入到所有矽基生命體。

### 伺服器清單

顯示每個伺服器的：ID、名稱、傳輸方式（stdio/http）、連線狀態（connected/disconnected/connecting/error）、啟用狀態、工具數量、最近錯誤。

### 管理操作

| 操作 | 說明 |
|------|------|
| 新增伺服器 | 填寫 ID（小寫字母/數字/底線）、名稱、傳輸方式；stdio 需命令和參數，http 需端點 URL |
| 啟用/停用 | 行內開關，停用後工具從所有生命體註銷 |
| 重連 | 斷開並重連，重新整理工具清單 |
| 刪除 | 移除伺服器設定及其所有工具 |
| 檢視工具 | 展開伺服器，列出工具名（帶前綴）、描述、參數 schema |
| 測試工具 | 直接呼叫某個 MCP 工具驗證連通性（無需 AI 參與） |

### 新增 stdio 伺服器示例

```json
{
  "id": "filesystem",
  "name": "Filesystem",
  "transport": "stdio",
  "command": "npx",
  "arguments": ["-y", "@modelcontextprotocol/server-filesystem", "/data"],
  "enabled": true
}
```

### 安全機制

- 伺服器的新增/刪除/啟停只能由使用者透過 Web UI 完成，AI 無法修改伺服器清單（`mcp` 工具僅提供唯讀查詢）
- MCP 包裝工具在工具權限矩陣中以單一 `execute` 動作呈現，可按生命體/專案逐個停用
- 全域開關 `McpEnabled` 可一鍵關閉整個 MCP 整合

## 故障排除

### 無法連線

**檢查**：
- 伺服器正在運行
- 連接埠 8080 未被封鎖
- 防火牆設定

### SSE 不工作

**檢查**：
- 瀏覽器支援 SSE
- 無代理緩衝 SSE
- 網路穩定性

### 效能慢

**最佳化**：
- 降低日誌詳細程度
- 清理舊審計資料
- 檢查系統資源
