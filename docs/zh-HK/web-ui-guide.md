# Web UI 指南

> **版本：v0.1.0-alpha**

[English](../en/web-ui-guide.md) | [中文](../zh-CN/web-ui-guide.md) | **繁體中文** | [Español](../es-ES/web-ui-guide.md) | [日本語](../ja-JP/web-ui-guide.md) | [한국어](../ko-KR/web-ui-guide.md) | [Čeština](../cs-CZ/web-ui-guide.md)

## 概述

Web UI 提供了一個全面的介面，用於管理矽基生命體、監控系統狀態和與 AI 智能體互動。

## 存取

預設 URL：`http://localhost:8080`

## 導航

### 主要部分

1. **儀表板** - 系統概覽和指標
2. **生命體** - 管理矽基生命體
3. **聊天** - 與生命體互動
4. **工作** - 工作管理
5. **定時器** - 定時器設定
6. **設定** - 系統設定
7. **權限** - 存取控制
8. **記錄** - 系統記錄
9. **稽核** - Token 使用和稽核追蹤
10. **記憶** - 生命體記憶
11. **知識** - 知識程式庫
12. **程式碼瀏覽器** - 程式碼探索
13. **程式碼編輯器** - 帶懸浮提示的程式碼編輯
14. **項目** - 項目管理
15. **執行器** - 執行器管理

## 儀表板

### 功能

- 系統效能指標（CPU、記憶體、執行時間）
- 生命體狀態概覽
- AI 使用統計
- 快速操作

### 即時更新

使用 SSE（伺服器發送事件）取得即時資料：

```javascript
const dashboard = new EventSource('/api/dashboard/events');
dashboard.onmessage = (event) => {
    const data = JSON.parse(event.data);
    updateMetrics(data);
};
```

## 設定

### AI 客戶端

設定 AI 後端：
- Ollama（本地）
- 百煉（雲端）
- 火山引擎 Ark（雲端）
- 自訂客戶端

### 儲存設定

- Default 版本：基礎路徑、時間索引、清理策略
- Fast 版本：SpeedyPack 儲存引擎配置、.spk 檔案管理、自動壓縮設定

### 在地化

在 29 種語言變體之間切換：
- 中文（6 種）：簡體中文、繁體中文、新加坡中文、澳門中文、台灣中文、馬來西亞中文
- 英文（10 種）：美式、英式、加拿大、澳大利亞、印度、新加坡、南非、愛爾蘭、紐西蘭、馬來西亞英語
- 德語（5 種）：德國、奧地利、瑞士、盧森堡、列支敦斯登
- 法語（3 種）：法國、加拿大、瑞士
- 日語、韓語、捷克語

## 皮膚系統

### 可用皮膚

1. **Admin** - 專業管理介面
2. **Chat** - 以對話為中心的設計
3. **Creative** - 創意和藝術風格
4. **Dev** - 面向開發者的佈局
5. **HighContrast** - 高對比度主題（Fast 版本）
6. **Minimal** - 極簡風格（Fast 版本）
7. **Light** - 明亮主題（Fast 版本）

### 切換皮膚

1. 點擊**設定**（齒輪圖示）
2. 選擇**皮膚**
3. 選擇所需皮膚
4. 介面立即更新

### 自訂皮膚

透過實現 `ISkin` 建立自訂皮膚：

```csharp
public class MySkin : ISkin
{
    public string Name => "MySkin";
    
    public string GetCss()
    {
        return ":root { --primary: #color; }";
    }
}
```

## 權限管理

### 查看權限

- 列出所有權限規則
- 按使用者或資源過濾

### 添加權限規則

1. 點擊**添加規則**

### 稽核追蹤

查看所有權限決策：
- 時間戳
- 使用者
- 資源
- 決策
- 原因

## 檔案上傳

### 功能说明
- 支援通過檔案來源對話框選擇檔案
- 將檔案上傳集成到聊天介面
- 檔案元資料管理（名稱、大小、類型）
- 實現上傳檔案的存取權限控制
- 包含上傳檔案的安全驗證和處理邏輯
- 在多個本地化檔案中添加上傳相關本地化字符串：
  - 英文、中文、粵語、日語、韓語本地化檔案中添加上傳按鈕和檔案來源對話框文本

### 檔案來源對話框實現細節：
- 實現點擊檔案選擇按鈕時顯示對話框的邏輯（約 80 行）
- 對話框狀態管理（開啟/關閉/檔案選擇）
- 顯示所選檔案資訊及確認/取消功能

## 載入指示器

### 聊天頁面載入指示器實現：
- 爲聊天頁面添加載入狀態指示器（50 行新增）
- 在 AI 回應生成過程中提供視覺回饋

### 主理人會話自動選擇：
- 實現聊天頁面載入時自動選擇主理人會話的功能（10 行新增）
- 設定自動焦點以提升使用者體驗

### 無法連接

**檢查**：
- 伺服器正在執行
- 連接埠 8080 未被封鎖
- 防火牆設定

### SSE 不工作

**檢查**：
- 瀏覽器支援 SSE
- 無代理緩衝 SSE
- 網路穩定性

### 效能慢

**最佳化**：
- 降低記錄詳細程度
- 清理舊稽核資料
- 檢查系統資源
