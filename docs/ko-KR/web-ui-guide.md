# Web UI 가이드

> **버전: v0.2.0-alpha**

[English](../en/web-ui-guide.md) | [Deutsch](../de-DE/web-ui-guide.md) | [中文](../zh-CN/web-ui-guide.md) | [繁體中文](../zh-HK/web-ui-guide.md) | [Español](../es-ES/web-ui-guide.md) | [日本語](../ja-JP/web-ui-guide.md) | **한국어** | [Čeština](../cs-CZ/web-ui-guide.md) | [Русский](../ru-RU/web-ui-guide.md)

## 개요

Web UI는 실리콘 비잉 관리, 시스템 상태 모니터링 및 AI 에이전트와의 상호작용을 위한 종합적인 인터페이스를 제공합니다. 시스템은 순수 서버 사이드 렌더링 아키텍처를 채택하고 있으며, 프론트엔드 프레임워크 의존성이 없고 `H`, `CssBuilder` 및 `JsBuilder` 빌더를 통해 HTML, CSS 및 JavaScript를 생성합니다.

## 접속

기본 URL: `http://localhost:8080`

## 내비게이션

### 주요 섹션

1. **대시보드** - 시스템 개요 및 지표
2. **비잉** - 실리콘 비잉 관리
3. **채팅** - 비잉과의 상호작용 (파일 업로드, 실시간 SSE 지원)
4. **채팅 기록** - 실리콘 비잉의 채팅 기록 조회 (세션 목록, 메시지 상세)
5. **태스크** - 태스크 관리 (개인 태스크)
6. **타이머** - 타이머 설정 (생성, 일시정지, 실행 기록)
7. **설정** - 시스템 설정 (AI 클라이언트, 로컬라이제이션)
8. **권한** - 접근 제어 (ACL 관리, 권한 조회)
9. **로그** - 시스템 로그 (레벨별 필터, 시간 범위 조회)
10. **감사** - 토큰 사용 및 감사 추적
11. **메모리** - 비잉 메모리 (타임라인 뷰, 고급 필터)
12. **지식** - 지식 베이스 (트리플렛 관리, 경로 탐색)
13. **코드 브라우저** - 코드 탐색 (파일 트리, 구문 하이라이팅)
14. **코드 편집기** - 호버 팁이 있는 코드 편집 (Monaco Editor)
15. **프로젝트** - 프로젝트 관리 (워크스페이스, 태스크, 워크 노트)
16. **이그제큐터** - 이그제큐터 관리 (디스크, 네트워크, 커맨드라인)
17. **도움말** - 도움말 문서 시스템 (다국어 지원, 주제 검색)
18. **정보** - 시스템 정보 및 버전

SSE (서버 전송 이벤트)를 사용하여 실시간 데이터를 가져옵니다:

```javascript
const dashboard = new EventSource('/api/dashboard/events');
dashboard.onmessage = (event) => {
    const data = JSON.parse(event.data);
    updateMetrics(data);
};
```

## 스킨 시스템

### 사용 가능한 스킨

1. **Admin** - 전문 관리 인터페이스
2. **Chat** - 대화 중심 디자인
3. **Creative** - 크리에이티브 및 아트 스타일

6. **Minimal** - 미니멀 스타일 (Fast 버전)
7. **Light** - 밝은 테마 (Fast 버전)

### 스킨 전환

1. **설정** 클릭 (톱니바퀴 아이콘)
2. **스킨** 선택
3. 원하는 스킨 선택
4. 인터페이스가 즉시 업데이트됨

### 커스텀 스킨

`ISkin`을 구현하여 커스텀 스킨을 생성합니다:

```csharp
public class MySkin : ISkin
{
    public string Name => "MySkin";

    public string GetCss()
    {
        return ":root { --primary: #color; }";
    }
}
```

## 권한 관리

### 권한 조회

- 모든 권한 규칙 나열
- 사용자 또는 리소스별 필터
- 만료 날짜 확인

### 권한 규칙 추가

1. **규칙 추가** 클릭
2. 설정:
   - 퍼미션 타입 (예: `FileAccess`, `NetworkAccess`)
   - 리소스 접두사 (예: `C:\Projects`, `api.github.com`)
   - 허용/거부
   - 설명
3. 저장

### 감사 추적

모든 권한 결정을 확인합니다:
- 타임스탬프
- 사용자
- 리소스
- 결정
- 사유

### 툴 권한 관리

실리콘 비잉 및 프로젝트의 툴 조작 권한을 관리합니다:

1. **실리콘 비잉 툴 권한**:
   - **비잉** → 비잉 선택 → **툴 권한**으로 이동
   - 현재 권한 설정 확인
   - 조작별로 허용/거부 설정
   - 권한 템플릿 적용 (readonly/restricted/full)

2. **프로젝트 툴 권한**:
   - **프로젝트** → 프로젝트 선택 → **툴 권한**으로 이동
   - 프로젝트 수준의 툴 권한은 실리콘 비잉 수준과 독립적
   - 프로젝트 간 권한 격리 구현

## 채팅 기록 조회

### 기능

- 실리콘 비잉 채팅 기록 탐색
- 세션 목록 표시
- 메시지 상세 조회
- 타임라인 뷰

### 채팅 기록 사용법

1. **비잉** 페이지로 이동
2. 실리콘 비잉의 **채팅 기록** 링크 클릭
3. 세션 목록 확인:
   - 세션 제목
   - 생성 시간
   - 메시지 수
4. 세션을 클릭하여 상세 확인:
   - 전체 메시지 기록
   - 타임스탬프
   - 발신자 정보
   - 툴 콜 기록

### 기술 구현

- **컨트롤러**: `ChatHistoryController`
- **뷰 모델**: `ChatHistoryViewModel`
- **뷰**:
  - `ChatHistoryListView` - 세션 목록
  - `ChatHistoryDetailView` - 메시지 상세
- **API 라우트**:
  - `/api/chat-history/{beingId}/conversations` - 세션 목록 조회
  - `/api/chat-history/{beingId}/conversation/{conversationId}` - 메시지 상세 조회

## 도움말 문서 시스템 (신규)

### 기능 개요

도움말 문서 시스템은 실리콘 비잉과 사용자에게 다국어 도움말 문서 지원을 제공합니다.

### 도움말 문서 사용법

1. **도움말** 페이지로 이동
2. 도움말 주제 목록 확인:
   - 빠른 시작 가이드
   - 툴 사용 참조
   - 권한 관리 가이드
   - 문제 해결 매뉴얼
   - 개발 가이드
3. 주제를 클릭하여 상세 내용 확인:
   - 구조화된 문서 콘텐츠 (Markdown 렌더링)
   - 다국어 지원 (시스템 로컬라이제이션 설정 따름)
   - 관련 주제 추천
4. 검색 기능으로 빠르게 찾기:
   - 키워드 검색 (한국어, 영어 지원)
   - 검색 결과 관련도 순 정렬

### 실리콘 비잉의 도움말 접근

실리콘 비잉은 `help` 툴을 통해 도움말 문서에 접근할 수 있습니다:
```json
{
  "action": "get_topics"
}
```

### 기술 구현

- **컨트롤러**: `HelpController`
- **툴**: `HelpTool`
- **API 라우트**:
  - `/api/help` - 도움말 주제 목록 조회
  - `/api/help/{topicId}` - 주제 상세 조회
  - `/api/help/search?q=keyword` - 도움말 문서 검색

## 프로젝트 워크스페이스 (신규)

### 기능 개요

프로젝트 워크스페이스는 구조화된 작업 환경을 제공하여 프로젝트 관리, 태스크 추적 및 워크 노트를 지원합니다.

### 프로젝트 관리

1. **프로젝트 생성**:
   - 프로젝트 이름 및 설명
   - 프로젝트 태그 (분류)
   - 프로젝트 상태 (진행 중, 완료, 보관됨)
2. **프로젝트 상세 조회**:
   - 프로젝트 기본 정보
   - 관련 태스크 목록
   - 워크 노트 목록
   - 프로젝트 진행 통계
3. **프로젝트 보관**: 기록 데이터는 유지하되 더 이상 활성화하지 않음
4. **프로젝트 역할 관리**:
   - 실리콘 비잉에 프로젝트 역할 할당 (예: developer, reviewer, manager)
   - 역할 할당 제거
   - 프로젝트 멤버 및 역할 목록 확인
5. **프로젝트 워크플로우**:
   - 워크플로우 템플릿 목록 확인
   - 프로젝트에 워크플로우 템플릿 바인딩
   - 워크플로우 인스턴스 상태 확인
   - 워크플로우 실행 로그 확인

### 워크 노트 (비공개)

실리콘 비잉의 개인 워크 노트로, 일기장과 유사합니다:

1. **노트 생성**:
   - 요약 (간단한 설명)
   - 내용 (Markdown 형식 지원)
   - 키워드 (검색용)
   - 자동 타임스탬프 기록
2. **노트 관리**:
   - 타임라인으로 탐색 (페이지 디자인)
   - 노트 검색 (키워드, 요약, 내용별)
   - 목차 생성 (노트 구조 빠르게 탐색)
   - 노트 업데이트 및 삭제
3. **권한 제어**:
   - 기본적으로 비공개이며, 비잉 본인만 접근 가능
   - 실리콘 큐레이터는 모든 노트를 관리할 수 있음

### 기술 구현

- **컨트롤러**: `WorkNoteController`
- **툴**: `WorkNoteTool`, `ProjectTool`, `ProjectWorkNoteTool`
- **API 라우트**:
  - `/api/worknotes` - 워크 노트 목록 조회
  - `/api/worknotes/{id}` - 노트 상세 조회
  - `/api/worknotes/search?q=keyword` - 노트 검색
  - `/api/worknotes/directory` - 노트 목차 생성
  - `/api/projects` - 프로젝트 관리 API

## 문제 해결

### 연결 불가

**확인 사항**:
- 서버가 실행 중인지 확인
- 포트 8080이 차단되지 않았는지 확인
- 방화벽 설정 확인

### SSE 작동 안 함

**확인 사항**:
- 브라우저가 SSE를 지원하는지 확인
- 프록시가 SSE를 버퍼링하지 않는지 확인
- 네트워크 안정성 확인

### 성능 저하

**최적화**:
- 로그 상세 수준 낮추기
- 오래된 감사 데이터 정리
- 시스템 리소스 확인
