## 듀얼 버전 로드맵

### SiliconLife.Default（디폴트 버전）
- **포지션**: 디폴트 구현, 주로 아키텍처 타당성 검증에 사용
- **현재 상태**: 단계 1-10.6 완료, 시스템 안정적 운영 중
- **역할 설명**: 아키텍처 검증의 베이스라인 구현으로서, 핵심 아키텍처 설계의 정확성과 타당성을 보장

### SiliconLife.Fast（고성능 버전）
- **포지션**: 주력 프로덕션 버전
- **현재 상태**: 기본 아키텍처 이식 완료, SpeedyPack 스토리지 엔진 및 플러그인 시스템 구현 완료
- **역할 설명**: Default 버전이 검증한 아키텍처를 기반으로 심층적인 성능 최적화와 프로덕션급 기능 강화를 수행하며, 실제 배포의 최우선 선택

**Fast 버전 개발 계획**:
- ✅ 단계 1: 기본 프로젝트 구조 및 설정 시스템 이식
- ✅ 단계 2: Web UI 및 컨트롤러 이식
- ✅ 단계 3: 스토리지 시스템 최적화（SpeedyPack 메모리 스토리지 + 비동기 영속화）
- ✅ 단계 3.5: SpeedyPack 매니저（SiliconLife.Speedy.Manager Avalonia UI 애플리케이션）
- ✅ 단계 3.6: 플러그인 시스템（IPlugin 인터페이스, 보안 샌드박스, AssemblyLoadContext 격리）
- ✅ 단계 4: Avalonia 윈도우 애플리케이션（크로스 플랫폼 데스크톱 앱, Windows/macOS 시스템 트레이, Linux 상태 창）

## 가이드 원칙

모든 단계는 **실행 가능하고 관찰 가능한** 시스템으로 종료됩니다. 어떤 단계도 "인프라만 있고 보여줄 것이 없는" 상태를 만들지 않습니다.

| # | 모듈 | 설명 |
|---|--------|-------------|
| 2.1 | 스토리지（최소화）| `IStorage` 인터페이스（Read/Write/Exists/Delete, 키-값 쌍）. `FileSystemStorage` 구현. 인스턴스 클래스（비정적）. 직접 파일 시스템 액세스 —— **AI는 IStorage를 제어할 수 없음** |

**검증**: 테스트 틱 오브젝트를 등록하여 매초 틱 카운트 출력; 콘솔 채팅이 여전히 작동함.

## ~~단계 6: 규칙 준수（퍼미션 시스템）~~ ✅ 완료

**목표**: 실리콘 비잉이 승인 없이 민감한 리소스에 접근할 수 없음.

| # | 모듈 | 설명 |
|---|--------|-------------|
| 6.1 | 퍼미션 매니저 | 각 비잉의 프라이빗 인스턴스. 콜백 기반, 삼항 결과（Allowed/Deny/AskUser）. 쿼리 우선순위: HighDeny → HighAllow → Callback. IsCurator 플래그 |
| 6.2 | 퍼미션 타입 열거형 | NetworkAccess, CommandLine, FileAccess, Function, DataAccess |
| 6.3 | DefaultPermissionCallback | 네트워크 화이트리스트/블랙리스트, CLI 분류, 파일 경로 보안 규칙 |
| 6.4 | 글로벌 ACL | 접두사 매칭 규칙 테이블, 스토리지에 영속화 |
| 6.5 | 사용자 빈도 캐시 | HighAllow/HighDeny 리스트. 사용자 선택（자동 감지 아님）. 접두사 매칭, 메모리 전용, 만료 설정 가능 |
| 6.6 | 사용자 요청 메커니즘（콘솔）| AskUser 반환 시 콘솔에서 y/n 프롬프트 |
| 6.7 | 이그제큐터 퍼미션 통합 | 모든 이그제큐터가 실행 전 퍼미션 체크 |
| 6.8 | IStorage 격리 설명 | IStorage는 시스템 내부 영속화 —— 직접 파일 액세스, 이그제큐터를 통해 라우팅되지 **않음**, AI가 제어할 수 **없음**. 이그제큐터는 AI 툴이 시작한 IO만 관리 |
| 6.9 | 감사 로그 | 모든 퍼미션 결정 기록, 타임스탬프, 요청자, 리소스, 결과 포함 |

**산출물**: 비잉이 민감한 작업을 시도할 때 퍼미션 프롬프트 표시.

**검증**: 비잉에게 파일 삭제 지시 → 콘솔에 퍼미션 프롬프트 표시 → `n` 입력 → 작업 거부됨. 비잉에게 화이트리스트 웹사이트 접근 지시 → 즉시 허용됨.
