# Silicon Life Collective

**Версия: v0.2.0-alpha** | **Silicon Life Collective** — платформа многомандатного сотрудничества на основе .NET 9, где AI-агенты называются **Кремниевыми Существами** и реализуют самоэволюцию через динамическую компиляцию Roslyn.

## 🌟 Ключевые особенности

### Система агентов
- **Мультиагентная оркестрация** — единое управление *Кремниевым Куратором* с механизмом справедливого планирования на основе временных интервалов
- **Управление Файлом Души** — каждое Кремниевое Существо управляется основным файлом подсказок (`soul.md`), определяющим уникальную личность и модели поведения
- **Архитектура Тело-Мозг** — *Тело* (SiliconBeing) поддерживает жизненные показатели и обнаруживает триггерные сценарии; *Мозг* (ContextManager) загружает историю, вызывает AI, выполняет инструменты и сохраняет ответы
- **Способность к самоэволюции** — через технологию динамической компиляции Roslyn Кремниевые Существа могут переписывать свой собственный код для эволюции
- **Управление активным состоянием** — поддержка девяти активных состояний: Idle (простой), SingleChat (личный чат), GroupChat (групповой чат), Task (задача), Timer (таймер), Broadcast (широковещание), Project (проект), MemoryCompression (сжатие памяти), Stopped (остановлен); при 10 последовательных ошибках автоматически переходит в состояние Stopped

### Система плагинов
- **Архитектура расширения плагинами** — расширение функциональности через интерфейс IPlugin, поддержка динамической загрузки DLL плагинов из каталога
- **Объявление возможностей плагинов** — плагины объявляют необходимые возможности через атрибут `[PluginCapability]` (Network, FileIO, Process, AI), и загрузчик на этом основании ослабляет правила безопасности; необъявляемые возможности (P/Invoke, Unsafe, Reflection Emit и т.д.) всегда блокируются
- **Изолированная загрузка** — использование пользовательского AssemblyLoadContext для изолированной загрузки, предотвращение влияния плагинов на стабильность основной программы
- **Интеграция инструментов** — плагины могут регистрировать пользовательские инструменты через интерфейс ITool, автоматически интегрируясь в цикл вызова инструментов

### Инструменты и выполнение
- **24 встроенных инструмента** — охватывают календарь, чат, конфигурацию, диск, сеть, память, задачи, таймеры, базу знаний, рабочие заметки, рабочее пространство проекта, задачи проекта, рабочие заметки проекта, работу проекта, WebView браузер, динамическую компиляцию, выполнение кода, управление разрешениями, аудит токенов, запросы журналов, базу данных, системную информацию, справочную документацию и др.
- **Изоляция сценариев инструментов** — каждый инструмент объявляет доступные сценарии через атрибут `ToolScenario` (Chat, Task, Timer, MemoryCompression, Project), атрибут `ChatOnly` ограничивает использование инструмента только в сценарии чата, атрибут `SiliconManagerOnly` ограничивает использование только Куратором
- **Цикл вызова инструментов** — AI возвращает вызов инструмента → выполнение инструмента → результат передаётся AI → цикл продолжается до получения текстового ответа
- **Безопасность Исполнитель-Разрешение** — все операции I/O проходят строгую проверку разрешений через Исполнители
  - 3-уровневая цепочка проверки разрешений: UserFrequencyCache → IPermissionCallback → (IsCurator: IPermissionAskHandler | Non-curator: GlobalACL → отказ по умолчанию)
  - Полный аудитный журнал всех решений о разрешениях

### AI и знания
- **Поддержка нескольких AI-бэкендов**
  - **Ollama** — локальное развёртывание моделей, использование нативного HTTP API
  - **Alibaba Cloud Bailian (DashScope)** — облачный AI-сервис, совместимый с OpenAI API, поддержка 13+ моделей, развёртывание в нескольких регионах
  - **Volcengine Ark** — облачный AI-сервис ByteDance, поддержка потокового и непотокового режимов, встроенный контроль скорости
  - **Herdsman** — движок вывода без аутентификации, совместимый с форматом OpenAI API
  - **Meituan LongCat** — собственная большая модель Meituan, совместимая с форматом OpenAI API, аутентификация по API Key
  - **Qiniu Cloud AI** — сервис вывода большой модели Qiniu Cloud, совместимый с форматом OpenAI API, аутентификация по API Key
  - **DeepSeek** — AI-сервис DeepSeek, режим thinking, 1M контекст, аутентификация по API Key
  - **Zhipu AI (GLM)** — AI-сервис Zhipu Qingyan, режим thinking (GLM-5), vision по модели, 1M контекст, бесплатная модель glm-4-flash
  - **Baidu Qianfan (Ernie)** — AI-сервис Baidu Wenxin, Qianfan v2 OpenAI-совместимый API, 131K контекст, бесплатные модели
  - **Tencent Hunyuan** — AI-сервис Tencent Hunyuan, двойной endpoint (TokenHub + Legacy), режим thinking, 262K контекст
  - **MiniMax** — AI-сервис MiniMax, thinking с reasoning_split, multimodal (M3), 1M контекст
  - **Moonshot (Kimi)** — AI-сервис Moonshot Kimi, режим thinking, vision, 262K контекст
  - **SiliconFlow** — агрегатор 100+ моделей открытого исходного кода, динамический список моделей, 1M контекст
- **Обнаружение возможностей AI-клиента** — интерфейс IAIClient поддерживает объявление потокового режима, вызова инструментов, визуального ввода, аудиоввода, размера контекстного окна и других возможностей; ContextManager адаптивно настраивает поведение на этой основе
- **32 календарные системы** — полное покрытие основных мировых календарей, включая григорианский, лунный, исламский, еврейский, японский, персидский, майя, китайский исторический и др.
- **Сеть Знаний** — граф знаний на основе триплетов (субъект-отношение-объект), поддержка хранения, запросов и поиска путей
- **Рабочее пространство проекта** — управление проектным пространством, поддержка создания/архивирования/уничтожения проектов, назначения ролей, рабочих заметок, отслеживания задач и изоляции разрешений инструментов
- **Движок рабочих процессов** — движок конечного автомата на основе шаблонов, поддержка пользовательских шаблонов рабочих процессов, переходов состояний, выполнения на основе Tick и управления жизненным циклом экземпляров
- **Механизм затухания памяти** — служба периодического затухания (MemoryFadeService), автоматически применяет алгоритм снижения важности и архивацию памяти для всех Кремниевых Существ каждый час

### Данные и хранение
- **Высокопроизводительное хранилище SpeedyPack** — версия Fast использует собственный движок хранения .spk, отображение каталогов в памяти + кэш записей + асинхронная очередь записи
- **Хранение файловой системы** — версия Default использует чистое хранение JSON в файловой системе
- **Запросы с временным индексом** — поддержка эффективных запросов по временному диапазону через интерфейс `ITimeStorage`
- **Автоматическая компрессия** — SpeedyPack поддерживает автоматическую периодическую компрессию для освобождения свободного пространства
- **Минимальные зависимости** — основная библиотека зависит только от Microsoft.CodeAnalysis.CSharp для динамической компиляции

## 🔄 Двухверсионная архитектура

Этот проект предоставляет две версии реализации для различных сценариев:

### SiliconLife.Default (версия по умолчанию)
- **Назначение**: реализация по умолчанию, в основном для проверки жизнеспособности архитектуры
- **Режим работы**: консольное приложение
- **Способ хранения**: чистое хранение JSON в файловой системе
- **Сценарии применения**: высокий уровень безопасности данных, ограниченные ресурсы памяти, небольшой объём данных
- **Особенности**: простота и надёжность, мгновенное сохранение данных, отсутствие риска потери данных в памяти
- **Описание роли**: базовая реализация для проверки архитектуры, подходит для первого знакомства, отладки разработки или приоритета безопасности данных
- **Команда запуска**: `dotnet run --project src/SiliconLife.Default`

### SiliconLife.Fast (высокопроизводительная версия)
- **Назначение**: основная производственная версия
- **Режим работы**: настольное приложение (системный трей Windows/macOS / окно состояния Linux)
- **Способ хранения**: хранение в памяти SpeedyPack + асинхронная пакетная персистентность (формат файла .spk)
- **Сценарии применения**: высокая параллельность, низкая задержка, большие объёмы данных
- **Поддержка платформ**: Windows/macOS (полная функциональность, включая системный трей), Linux (окно состояния, без значка в трее)
- **Особенности**:
  - Экстремальная оптимизация производительности
  - Фоновая работа в системном трее Windows/macOS, мониторинг в реальном времени через окно состояния трея; прямое отображение окна состояния на Linux
  - Движок SpeedyPack + автоматическая компрессия гарантируют безопасность данных
  - Компонентная архитектура UI, 27 декларативных компонентов
  - 7 тем оформления, поддержка автоматического обнаружения и переключения
- **Повышение производительности**: задержка чтения хранилища снижена в 1000 раз, задержка записи снижена в 15000 раз, параллельная обработка увеличена в 50 раз
- **Описание роли**: глубоко оптимизированная производственная реализация, предпочтительный выбор для длительной работы и реальных производственных сред
- **Команда запуска**: `dotnet run --project src/SiliconLife.Fast`

### Сравнение версий

| Характеристика | SiliconLife.Default | SiliconLife.Fast |
|------|---------------------|------------------|
| **Режим работы** | Консольное приложение | Настольное приложение (системный трей Windows/macOS / окно состояния Linux) |
| **Пользовательский интерфейс** | Web UI (доступ через браузер) | Windows/macOS: значок трея + окно трея + Web UI; Linux: окно состояния + Web UI |

| **Потребление памяти** | ~200МБ | ~500МБ |
| **Безопасность данных** | Очень высокая (мгновенная персистентность) | Высокая (асинхронная персистентность + автоматическая компрессия) |

## 🏗️ Обзор архитектуры

### Архитектура планирования
```
Основной Цикл (выделенный поток, сторожевой таймер + автоматический выключатель)
  └── Объект Часов (отсортированы по приоритету)
       └── Менеджер Кремниевых Существ
            └── Бегунок Кремниевого Существа (временный поток, тайм-аут + автоматический выключатель)
                 └── Кремниевое Существо.Tick()
                      └── Менеджер Контекста.Думать()
                           └── AI-клиент.Чат()
                                └── Цикл вызова инструментов → Персистентность в систему чата
```

### Архитектура безопасности
Все операции I/O, инициированные AI, должны проходить через строгую цепочку безопасности:

```
Вызов инструмента → Исполнитель → Менеджер Разрешений → [Частотный Кэш → Обратный Вызов → (IsCurator: Спросить Пользователя | Non-curator: Глобальный ACL)]
```

  - **Volcengine Ark**: Получите API-ключ в [Консоли Volcengine](https://console.volcengine.com/ark)

### Сборка проекта

```bash
dotnet restore
dotnet build
```

### Запуск системы

#### Способ 1: Запуск версии Default (консольное приложение)

```bash
dotnet run --project src/SiliconLife.Default
```

Приложение запустит веб-сервер и автоматически откроет Web UI в браузере.

**Сценарии применения**:
- ✅ Высокие требования к безопасности данных
- ✅ Ограниченные ресурсы памяти (RAM < 2ГБ)
- ✅ Небольшой объём данных, краткосрочное использование
- ✅ Этап отладки разработки

#### Способ 2: Запуск версии Fast (настольное приложение)

```bash
dotnet run --project src/SiliconLife.Fast
```

**Windows/macOS**: Приложение запустится в оконном режиме, свернётся в системный трей и будет работать в фоновом режиме.

**Linux**: Приложение отобразит окно состояния (без значка в системном трее) и автоматически откроет браузер для доступа к Web UI. Также можно использовать параметр `--no-tray` для пропуска автоматического открытия браузера:

```bash
dotnet run --project src/SiliconLife.Fast -- --no-tray
```

**Сценарии применения**:
- ✅ Высокая параллельность (> 5 пользователей)
- ✅ Большие объёмы данных (использование более 3 месяцев)
- ✅ Необходимость низких задержек ответа
- ✅ Необходимость фоновой работы в трее
