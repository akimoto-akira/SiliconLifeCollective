## Выбор версии

Этот проект предлагает две версии реализации:

### SiliconLife.Default (Стандартная версия)
- **Позиционирование**: Стандартная реализация, в основном для проверки архитектурной осуществимости
- **Режим выполнения**: Консольное приложение
- **Хранение**: Хранение JSON в файловой системе
- **Сценарий использования**: Приоритет безопасности данных, небольшой объём данных, отладка разработки, проверка архитектуры
- **Поддержка платформ**: Windows, Linux, macOS
- **Описание роли**: Эталонная реализация для проверки архитектуры, обеспечивает простое и надёжное выполнение, подходит для первого знакомства или отладки разработки

### SiliconLife.Fast (Высокопроизводительная версия)
- **Позиционирование**: Основная производственная версия
- **Режим выполнения**: Настольное приложение (Windows/macOS системный трей / Linux окно статуса)
- **Хранение**: Хранение в памяти SpeedyPack + асинхронное сохранение (формат файла .spk)
- **Сценарий использования**: Высокая параллельность, низкая задержка, большой объём данных, долгосрочная производственная эксплуатация
- **Поддержка платформ**: Windows/macOS (полный функционал, включая системный трей), Linux (окно статуса, без иконки в трее)
- **Описание роли**: Готовая к производству реализация с глубокой оптимизацией, лучший выбор для долгосрочной эксплуатации и реальных производственных сред

> **Рекомендация для начинающих**: Новым пользователям следует начать с **SiliconLife.Default** для быстрой проверки архитектурной осуществимости. После ознакомления с системой настоятельно рекомендуется переход на **SiliconLife.Fast**.

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/akimoto-akira/SiliconLifeCollective.git
cd SiliconLifeCollective
```

### 2. Сборка проекта

```bash
dotnet build
```

### 3. Настройка ИИ-бэкенда

Отредактируйте `src/SiliconLife.Default/Config/DefaultConfigData.cs` или измените конфигурацию во время выполнения через веб-интерфейс.

#### Вариант A: Ollama (локальный)

```json
{
  "AIClients": {
    "Ollama": {
      "BaseUrl": "http://localhost:11434",
      "Model": "qwen2.5:7b"
    }
  }
}
```

#### Вариант B: DashScope (облако)

```json
{
  "AIClients": {
    "DashScope": {
      "ApiKey": "ваш-api-ключ-здесь",
      "Model": "qwen3.6-plus",
      "Region": "beijing"
    }
  }
}
```

#### Вариант C: Volcengine Ark (облако)

```json
{
  "AIClients": {
    "VolcengineArk": {
      "ApiKey": "ваш-api-ключ-здесь",
      "Endpoint": "https://ark.cn-beijing.volces.com/api/v3/chat/completions",
      "Model": "ep-xxxxxxxxxxxxx-xxxxx"
    }
  }
}
```

> **Примечание**: Параметр Model для Volcengine Ark принимает ID конечной точки вывода (например, `ep-20241212123456-abcde`), а не имя модели.

### 4. Запуск приложения

#### Запуск версии Default

```bash
cd src/SiliconLife.Default
dotnet run
```

Веб-сервер запускается на `http://localhost:8080`

#### Запуск версии Fast

```bash
cd src/SiliconLife.Fast
dotnet run
```

**Windows/macOS**: Приложение запускается в режиме Forms, сворачивается в системный трей, веб-сервер также на `http://localhost:8080`

**Linux**: Приложение отображает окно статуса (без иконки в системном трее) и автоматически открывает браузер для доступа к веб-интерфейсу. Можно использовать параметр `--no-tray` для пропуска автоматического открытия браузера:

```bash
dotnet run -- --no-tray
```

### 5. Доступ к веб-интерфейсу

Откройте браузер и перейдите по адресу:

```
http://localhost:8080
```

Вы увидите панель управления с:
- Управлением Silicon Beings
- Интерфейсом чата
- Панелью конфигурации
- Мониторингом системы

## Ваш первый Silicon Being

### Создание первого Being

1. В веб-интерфейсе перейдите в раздел **Управление Beings**
2. Нажмите **Создать новый Being**
3. Настройте файл души (`soul.md`) с личностью и поведением
4. Запустите Being

### Пример soul.md

```markdown
# Мой первый Silicon Being

## Личность
Вы — полезный помощник, специализирующийся на ревью кода.

## Способности
- Оценивать качество кода
- Предлагать улучшения
- Объяснять сложные концепции

## Поведение
- Всегда предоставлять конструктивную обратную связь
- Использовать ясные примеры
- Быть кратким, но исчерпывающим
```

## Часто задаваемые вопросы

### Ошибка подключения к Ollama

**Проблема**: Невозможно подключиться к Ollama на `http://localhost:11434`

**Решение**:
```bash
# Проверить, работает ли Ollama
ollama list

# Запустить Ollama при необходимости
ollama serve
```

### Модель не найдена

**Проблема**: `model "qwen2.5:7b" not found`

**Решение**:
```bash
# Скачать необходимую модель
ollama pull qwen2.5:7b
```

### Порт уже занят

**Проблема**: `HttpListenerException: Address already in use`

**Решение**:
- Изменить порт в конфигурации
- Или завершить процесс на порту 8080:

```bash
# Windows
netstat -ano | findstr :8080
taskkill /PID <PID> /F

# Linux/Mac
lsof -ti:8080 | xargs kill -9
```
