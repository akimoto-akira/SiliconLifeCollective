## Вклад в двойную версию

Этот проект имеет две версии реализации. Вы можете вносить вклад в зависимости от ваших интересов:

### SiliconLife.Default (Стандартная версия)
- **Технологический стек**: Консольное приложение .NET 9
- **Направление вклада**: Разработка основных функций, реализация инструментов, локализация, документация
- **Целевая аудитория**: Все разработчики

### SiliconLife.Fast (Высокопроизводительная версия)
- **Технологический стек**: Настольное приложение Windows Forms .NET 9
- **Направление вклада**: Оптимизация производительности, хранение SpeedyPack, системный трей, неблокирующая параллельность
- **Целевая аудитория**: Разработчики с опытом работы на Windows и интересом к оптимизации производительности

> **Важное примечание**: Обе версии используют общие проекты SiliconLife.Core и SiliconLife.Common. Улучшения основных интерфейсов затрагивают обе версии.
