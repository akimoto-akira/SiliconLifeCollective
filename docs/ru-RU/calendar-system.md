## Обзор

SiliconLifeCollective поддерживает 32 различные календарные системы для преобразования дат и исторической точности.

## Поддерживаемые календари (32)

### Основные календари (6)

1. **Григорианский (Gregorian)** — международный стандартный календарь, ID: `gregorian`
2. **Китайский лунный (Chinese Lunar)** — традиционный китайский календарь с вычислением високосных месяцев, ID: `lunar`
3. **Исламский (Islamic)** — исламский календарь хиджры, ID: `islamic`
4. **Еврейский (Hebrew)** — еврейский календарь, ID: `hebrew`
5. **Персидский (Persian)** — иранский солнечный календарь, ID: `persian`
6. **Индийский (Indian)** — национальный индийский календарь, ID: `indian`

### Китайские исторические календари (2)

7. **Китайский исторический (Chinese Historical)** — поддержка летоисчисления гань-чжи и императорских эр, ID: `chinese_historical`
   - **Летоисчисление гань-чжи**: 60-летний цикл (небесные стволы + земные ветви)
   - **Императорские эры**: поддержка эр китайских исторических династий (Канси, Цяньлун, Чжэньгуань и др.)
   - **Динамическая база данных**: встроенная полная база данных китайских исторических династий и эр
8. **Гань-чжи (Sexagenary)** — 60-летний цикл гань-чжи, ID: `sexagenary`

### Восточноазиатские календари (6)

9. **Японский (Japanese)** — японский календарь эр (Нэнго), ID: `japanese`
10. **Вьетнамский (Vietnamese)** — вьетнамский лунный календарь (вариант с зодиаком Кота), ID: `vietnamese`
11. **Тибетский (Tibetan)** — тибетская календарная система, ID: `tibetan`
12. **Монгольский (Mongolian)** — монгольский календарь, ID: `mongolian`
13. **Дай (Dai)** — календарь дай с полным лунным вычислением, ID: `dai`
14. **Дай Дэхун (Dehong Dai)** — вариант календаря дай Дэхун, ID: `dehong_dai`

### Исторические календари (6)

15. **Майя (Mayan)** — длинный счёт майя, ID: `mayan`
16. **Римский (Roman)** — древнеримский календарь, ID: `roman`
17. **Юлианский (Julian)** — юлианский календарь, ID: `julian`
18. **Французский республиканский (French Republican)** — календарь Французской революции, ID: `french_republican`
19. **Коптский (Coptic)** — коптский православный календарь, ID: `coptic`
20. **Эфиопский (Ethiopian)** — эфиопский календарь, ID: `ethiopian`

### Региональные календари (6)

22. **Сака (Saka)** — эра Сака (Индонезия), ID: `saka`

### Современные календари (3)

28. **Чучхе (Juche)** — северокорейский календарь, год - 1911, ID: `juche`

## Использование календарного инструмента

### Базовое преобразование

```json
{
  "action": "convert",
  "date": "2026-04-20",
  "fromCalendar": "gregorian",
  "toCalendar": "chinese_lunar"
}
```

**Ответ**:
```json
{
  "result": "Лунный календарь, год Бин-У, 4-й месяц, 3-й день",
  "year": 2026,
  "month": 4,
  "day": 3,
  "leapMonth": false
}
```

### Мультикалендарный запрос

```json
{
  "action": "query_all",
  "date": "2026-04-20"
}
```

**Ответ**: возвращает дату во всех 32 календарных системах.

## Календарный API

### Интерфейс CalendarBase

```csharp
public abstract class CalendarBase
{
    public abstract string Name { get; }
    
    public abstract CalendarDate ConvertFromGregorian(GregorianDate date);
    
    public abstract GregorianDate ConvertToGregorian(CalendarDate date);
    
    public virtual bool IsLeapYear(int year) => false;
    
    public virtual int GetDaysInMonth(int year, int month) => 30;
}
```

### Пример: пользовательский календарь

```csharp
public class MyCustomCalendar : CalendarBase
{
    public override string Name => "MyCalendar";
    
    public override CalendarDate ConvertFromGregorian(GregorianDate date)
    {
        // Логика преобразования
        return new CalendarDate(year, month, day);
    }
    
    public override GregorianDate ConvertToGregorian(CalendarDate date)
    {
        // Обратное преобразование
        return new GregorianDate(year, month, day);
    }
}
```

## Специальные функции

### Подробно о китайском историческом календаре (новое)

Китайский исторический календарь — одна из ключевых особенностей системы, поддерживающая две основные функции:

#### 1. Система летоисчисления гань-чжи

Использует 60-летний цикл, образованный комбинацией небесных стволов и земных ветвей:

```
Небесные стволы (10): 甲, 乙, 丙, 丁, 戊, 己, 庚, 辛, 壬, 癸
Земные ветви (12): 子, 丑, 寅, 卯, 辰, 巳, 午, 未, 申, 酉, 戌, 亥
```

**Примеры**:
- 2026 год = год Бин-У (丙午)
- 2025 год = год И-Сы (乙巳), год Змеи
- 2024 год = год Цзя-Чэнь (甲辰), год Дракона

**Пример использования**:
```json
{
  "action": "convert",
  "date": "2026-04-26",
  "from_calendar": "gregorian",
  "to_calendar": "chinese_historical"
}
```

**Ответ**:
```json
{
  "result": "Год Бин-У, 3-й месяц, 9-й день",
  "ganzhi_year": "丙午",
  "zodiac": "Лошадь"
}
```

#### 2. Система императорских эр

Встроена полная база данных китайских исторических династий и императорских эр:

**Поддерживаемые династии** (частично):
- Династия Цин: Канси, Юнчжэн, Цяньлун, Цзяцин, Даогуан, Сяньфэн, Тунчжи, Гуансюй, Сюаньтун
- Династия Мин: Хуну, Юнлэ, Цзяцзин, Ваньли, Чунчжэнь и др.
- Династия Тан: Чжэньгуань, Кайюань, Тяньбао и др.
- Династия Хань: Цзяньюань, Юаньгуан, Юаньшо и др.
- Другие династии...

**Пример использования**:
```json
{
  "action": "convert",
  "date": "1721-04-12",
  "from_calendar": "gregorian",
  "to_calendar": "chinese_historical"
}
```

**Ответ**:
```json
{
  "result": "Канси, 60-й год, 3-й месяц, 15-й день",
  "era": "Канси",
  "era_year": 60,
  "dynasty": "Цин"
}
```

### Обработка високосных месяцев

Календари с високосными месяцами:

## Точность календарей

### Астрономические вычисления

- На основе реальных астрономических данных
- Поддержка исторических дат
- Обработка календарных реформ

### Известные ограничения

- Некоторые древние даты являются приблизительными
- Календарные реформы различаются по регионам
- Не включает обработку високосных секунд

## Лучшие практики

### 1. Всегда указывайте календарь

Никогда не предполагайте календарную систему:

```json
{
  "date": "2026-04-20",
  "calendar": "gregorian"  // Укажите явно!
}
```

### 2. Обрабатывайте некорректные даты

Некоторые даты не существуют в определённых календарях:

```json
{
  "error": "Invalid date: February 30 doesn't exist"
}
```

### 3. Учитывайте часовые пояса

Преобразование дат может отличаться в зависимости от часового пояса:

```
2026-04-20 23:00 UTC+8
≠
2026-04-20 23:00 UTC-5
```
