## Двухверсионная дорожная карта

### SiliconLife.Default (версия по умолчанию)
- **Назначение**: реализация по умолчанию, в основном для проверки жизнеспособности архитектуры
- **Текущий статус**: этапы 1-10.6 завершены, система стабильно работает
- **Описание роли**: выступает в качестве базовой реализации для проверки архитектуры, обеспечивая корректность и жизнеспособность основного архитектурного проекта

### SiliconLife.Fast (высокопроизводительная версия)
- **Назначение**: основная производственная версия
- **Текущий статус**: завершена миграция базовой архитектуры, движок хранения SpeedyPack и система плагинов реализованы
- **Описание роли**: на основе архитектуры, проверенной версией Default, проводится глубокая оптимизация производительности и расширение производственных функций, является предпочтительным выбором для реального развёртывания

**План разработки версии Fast**:
- ✅ Этап 1: миграция базовой структуры проекта и системы конфигурации
- ✅ Этап 2: миграция Web UI и контроллеров
- ✅ Этап 3: оптимизация системы хранения (хранилище в памяти SpeedyPack + асинхронная персистентность)
- ✅ Этап 3.5: инструмент управления SpeedyPack (приложение Avalonia UI SiliconLife.Speedy.Manager)
- ✅ Этап 3.6: система плагинов (интерфейс IPlugin, Песочница Безопасности, изоляция AssemblyLoadContext)
- ✅ Этап 4: оконное приложение Avalonia (кроссплатформенное настольное приложение, системный трей Windows/macOS, окно состояния Linux)

## Руководящие принципы

Каждый этап завершается **работающей, наблюдаемой** системой. Ни один этап не создаёт «кучу инфраструктуры без чего-либо, что можно показать».
