## О этом журнале изменений

### Двойная версия проекта

Этот проект предлагает две версии реализации:

- **SiliconLife.Default**: Стандартная реализация, в основном для проверки архитектурной осуществимости. Консольное приложение, хранение JSON в файловой системе.
- **SiliconLife.Fast**: Основная производственная версия. Кроссплатформенное настольное приложение (Windows / macOS / Linux), хранение в памяти SpeedyPack + асинхронное сохранение, глубокая оптимизация производительности.

Обе версии используют одни и те же интерфейсы и функциональность, различаясь только в реализации хранения и режиме выполнения. SiliconLife.Default служит эталоном для проверки архитектуры, SiliconLife.Fast — основная рекомендуемая версия для производства.

### История проекта

- Этот проект начался 20 марта 2026 года.
- До этого проекта демо-версия проверки не удалась из-за неадекватной архитектурной концепции, что сделало невозможной интеграцию с несколькими ИИ-платформами.

### Используемые инструменты AI IDE

#### Kiro (Amazon AWS)
- Проект изначально поддерживался Kiro, запущенным в режиме Spec.
- Kiro — это агентная среда разработки ИИ, созданная Amazon AWS.
- Основана на Code OSS (VS Code), поддерживает настройки VS Code и плагины, совместимые с Open VSX.
- Процесс разработки на основе спецификаций для структурированного ИИ-кодирования.

#### Comate AI IDE / 文心快码 (Baidu)
- Иногда использовался для написания и документации.
- Comate AI IDE — инструмент среды разработки с нативным ИИ, выпущенный Baidu Wenxin 23 июня 2025 года.
- Первый в отрасли мультимодальный и многоагентный совместный ИИ IDE.
- Функции включают преобразование дизайн-код и ИИ-ассистированное кодирование по всему процессу.
- Работает на модели Baidu Wenxin 4.0 X1 Turbo.

#### Trae (ByteDance)
- Использовался с октября 2025 по апрель 2026.
- ИИ IDE с интеллектуальной генерацией кода и управлением проектами.

#### Qoder (Alibaba)
- Используется для поддержки проекта с 18 апреля 2026 года.
- Платформа ИИ-кодирования, поддерживающая анализ кода, генерацию документации и многоагентное сотрудничество.
