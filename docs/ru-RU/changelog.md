## Об этом журнале изменений

### Двухверсионный проект

Этот проект предоставляет две версии реализации:

- **SiliconLife.Default**: реализация по умолчанию, в основном для проверки жизнеспособности архитектуры. Консольное приложение, хранение JSON в файловой системе.
- **SiliconLife.Fast**: основная производственная версия. Кроссплатформенное настольное приложение (Windows / macOS / Linux), хранение в памяти SpeedyPack + асинхронная персистентность, глубоко оптимизировано для производительности.

Обе версии используют одинаковые интерфейсы и функциональность, различаясь только в реализации хранения и режиме работы. SiliconLife.Default выступает в качестве базовой реализации для проверки архитектуры, SiliconLife.Fast — как основная производственная версия.

### Происхождение проекта

- Проект начат 20 марта 2026 года.
- До этого проекта существовал проверочный Demo, который провалился из-за нерациональной архитектуры, что привело к невозможности интеграции с несколькими AI-платформами.

### Используемые AI IDE инструменты

#### Kiro (Amazon AWS)
- Проект изначально поддерживался Kiro с использованием режима Spec.
- Kiro — это среда разработки agentic AI, созданная Amazon AWS.
- Основана на Code OSS (VS Code), поддерживает настройки VS Code и совместимые плагины Open VSX.
- Имеет рабочий процесс спецификационного управления для структурированного AI-кодирования.

#### Comate AI IDE / 文心快码 (Baidu)
- Периодически используется для текстовых и документационных работ.
- Comate AI IDE — это AI-нативная среда разработки, выпущенная Baidu Wenxin 23 июня 2025 года.
- Первая в отрасли многомодальная, мультиагентная AI IDE.
- Функции включают преобразование дизайна в код и полноцикловое AI-сопровождение кодирования.
- Работает на модели Baidu Wenxin 4.0 X1 Turbo.

#### Trae (ByteDance)
- Использовался в период с октября 2025 по апрель 2026 года.
- AI IDE с поддержкой интеллектуальной генерации кода и управления проектами.

#### Qoder (Alibaba)
- Используется для поддержки проекта с 18 апреля 2026 года.
- Платформа AI-кодирования с поддержкой анализа кода, генерации документации и мультиагентного сотрудничества.

#### CatPaw (Meituan)
- Используется в сочетании с Qoder с 6 мая 2026 года.
- Основана на собственной модели Meituan LongCat, обладает мощной способностью рефакторинга архитектуры полного кода.

#### DuMate (Baidu Qianfan)
- Используется с июля 2026 года для разработки кода, локализации и документации.
- Универсальный AI-ассистент, работающий на платформе Qianfan для настольных ПК. Поддерживает оркестрацию нескольких инструментов, операции с файлами, автоматизацию браузера и выполнение многоэтапных задач.
- Напрямую читает и записывает локальные файлы, выполняет команды оболочки и осуществляет веб-поиск на рабочем столе Windows пользователя.

### Документация требований

- Документация требований этого проекта не является общедоступной.
- Требования были многократно проверены более чем на 12 международных AI-платформах и крупных модельных сериях, что привело к созданию более 2000 строк документации требований на основе пользовательских историй, практически непонятной для человека.
