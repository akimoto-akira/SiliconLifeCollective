## Обзор

Система инструментов позволяет Silicon Beings взаимодействовать с внешним миром через стандартизированный интерфейс. Каждый инструмент реализует интерфейс `ITool`, автоматически обнаруживаемый и регистрируемый `ToolManager` через рефлексию.

### Категории инструментов

- **Инструменты системного администрирования** — Конфигурация, разрешения, динамическая компиляция
- **Инструменты коммуникации** — Чат, сетевые запросы
- **Инструменты хранения данных** — Дисковые операции, база данных, память, рабочие заметки
- **Инструменты управления временем** — Календарь, таймеры, задачи
- **Инструменты разработки** — Выполнение кода, просмотр журналов
- **Служебные инструменты** — Системная информация, аудит токенов, справочная документация, сеть знаний
- **Инструменты браузера** — Автоматизация браузера WebView
- **Инструменты плагинов** — Сторонние инструменты, зарегистрированные через систему плагинов
