## Обзор

Web UI предоставляет комплексный интерфейс для управления Кремниевыми Существами, мониторинга состояния системы и взаимодействия с AI-агентами. Система использует чистую серверную архитектуру рендеринга, без зависимостей от фронтенд-фреймворков, генерируя HTML, CSS и JavaScript через построители `H`, `CssBuilder` и `JsBuilder`.

## Доступ

URL по умолчанию: `http://localhost:8080`

## Навигация

### Основные разделы

1. **Панель управления** — обзор системы и метрики
2. **Существа** — управление Кремниевыми Существами
3. **Чат** — взаимодействие с существами (поддержка загрузки файлов, SSE в реальном времени)
4. **История чата** — просмотр истории чатов Кремниевых Существ (список сессий, детали сообщений)
5. **Задачи** — управление задачами (личные задачи)
6. **Таймеры** — конфигурация таймеров (создание, приостановка, история выполнения)
7. **Конфигурация** — системные настройки (AI-клиенты, локализация)
8. **Разрешения** — контроль доступа (управление ACL, запрос разрешений)
9. **Журналы** — системные журналы (фильтрация по уровню, запрос по временному диапазону)
10. **Аудит** — использование токенов и аудитный след
11. **Память** — память существ (временная шкала, расширенная фильтрация)
12. **Знания** — база знаний (управление триплетами, обнаружение путей)
13. **Обозреватель кода** — исследование кода (дерево файлов, подсветка синтаксиса)
14. **Редактор кода** — редактирование кода с всплывающими подсказками (Monaco Editor)
15. **Проекты** — управление проектами (рабочее пространство, задачи, рабочие заметки)
16. **Исполнители** — управление Исполнителями (диск, сеть, командная строка)
17. **Справка** — система справочной документации (многоязычная поддержка, поиск по темам)
18. **О проекте** — системная информация и версия

## Панель управления

### Функции

- Метрики производительности системы (CPU, память, время работы)
- Обзор статуса существ
- Статистика использования AI
- Быстрые действия

### Обновления в реальном времени

Использование SSE (Server-Sent Events) для получения данных в реальном времени:

```javascript
const dashboard = new EventSource('/api/dashboard/events');
dashboard.onmessage = (event) => {
    const data = JSON.parse(event.data);
    updateMetrics(data);
};
```

### Список существ

Отображение всех существ, включая:
- Имя и ID
- Текущий статус (работает/остановлено/ошибка)
- Ссылка на Файл Души
- Быстрые действия (запуск/остановка/конфигурация)

### Детали существа

- Полная конфигурация
- Редактор Файла Души
- История задач
- Просмотрщик памяти
- Метрики производительности

1. Нажмите **Создать новое существо**
2. Заполните:
   - Имя
   - Содержание Файла Души (редактор Markdown)
   - Начальная конфигурация
3. Нажмите **Создать**

- Ollama (локальный)

- Французский (3 варианта): французский, канадский, швейцарский

## Система тем

### Доступные темы

1. **Admin** — профессиональный административный интерфейс
2. **Chat** — дизайн, центрированный на диалогах
3. **Creative** — творческий и художественный стиль
4. **Dev** — макет, ориентированный на разработчиков
5. **HighContrast** — тема высокой контрастности (версия Fast)
6. **Minimal** — минималистичный стиль (версия Fast)
7. **Light** — светлая тема (версия Fast)

### Переключение тем

1. Нажмите **Настройки** (иконка шестерёнки)
2. Выберите **Тема**
3. Выберите нужную тему
4. Интерфейс обновится немедленно

### Пользовательская тема

Создание пользовательской темы через реализацию `ISkin`:

```csharp
public class MySkin : ISkin
{
    public string Name => "MySkin";
    
    public string GetCss()
    {
        return ":root { --primary: #color; }";
    }
}
```

## Управление разрешениями

### Просмотр разрешений

- Список всех правил разрешений
- Фильтрация по пользователю или ресурсу
- Просмотр дат истечения

### Добавление правила разрешений

1. Нажмите **Добавить правило**
2. Настройте:
   - Тип разрешения (например, `FileAccess`, `NetworkAccess`)
   - Префикс ресурса (например, `C:\Projects`, `api.github.com`)
   - Разрешить/Отказать
   - Описание
3. Сохраните

### Аудитный след

Просмотр всех решений о разрешениях:
- Метка времени
- Пользователь
- Ресурс
- Решение
- Причина

### Управление разрешениями инструментов

Управление разрешениями операций инструментов для Кремниевых Существ и проектов:

1. **Разрешения инструментов Кремниевого Существа**:
   - Перейдите в **Существа** → выберите существо → **Разрешения инструментов**
   - Просмотр текущей конфигурации разрешений
   - Установка разрешения/отказа для каждой операции
   - Применение шаблона разрешений (readonly/restricted/full)

2. **Разрешения инструментов проекта**:
   - Перейдите в **Проекты** → выберите проект → **Разрешения инструментов**
   - Разрешения инструментов на уровне проекта независимы от уровня Кремниевого Существа
   - Реализация изоляции разрешений между проектами

## Загрузка файлов

### Функции

- Диалог выбора источника файлов
- Поддержка загрузки нескольких файлов
- Управление метаданными файлов
- Отображение прогресса загрузки

### Использование загрузки файлов

1. В интерфейсе чата нажмите кнопку **Загрузить файл**
2. Откроется диалог выбора источника файлов
3. Выберите источник файлов:
   - Локальный файл
   - Путь файловой системы
4. Выберите файлы (поддерживается множественный выбор)
5. Подтвердите загрузку
6. Информация о файле будет прикреплена к сообщению

### Поддерживаемые типы файлов

- Текстовые файлы (.txt, .md, .json, .xml и др.)
- Файлы кода (.cs, .js, .py, .java и др.)
- Файлы конфигурации (.yml, .yaml, .ini, .conf и др.)
- Файлы документов (.csv, .log и др.)

## Система справочной документации (новое)

### Обзор функций

Система справочной документации предоставляет многоязычную поддержку справочной документации для Кремниевых Существ и пользователей.

### Использование справочной документации

1. Перейдите на страницу **Справка**
2. Просмотрите список тем справки:
   - Руководство быстрого старта
   - Справочник использования инструментов
   - Руководство по управлению разрешениями
   - Руководство по устранению неполадок
   - Руководство разработчика
3. Нажмите на тему для просмотра подробного содержания:
   - Структурированное содержание документации (рендеринг Markdown)
   - Многоязычная поддержка (следует системным настройкам локализации)
   - Рекомендации связанных тем
4. Используйте функцию поиска для быстрого нахождения:
   - Поиск по ключевым словам (поддержка китайского, английского)
   - Результаты поиска отсортированы по релевантности

### Доступ Кремниевых Существ к справке

Кремниевые Существа могут обращаться к справочной документации через инструмент `help`:
```json
{
  "action": "get_topics"
}
```

### Техническая реализация

- **Контроллер**: `HelpController`
- **Инструмент**: `HelpTool`
- **API-маршруты**:
  - `/api/help` — получение списка тем справки
  - `/api/help/{topicId}` — получение деталей темы
  - `/api/help/search?q=keyword` — поиск справочной документации

## Рабочее пространство проекта (новое)

### Обзор функций

Рабочее пространство проекта предоставляет структурированную рабочую среду с поддержкой управления проектами, отслеживания задач и рабочих заметок.

### Управление проектами

1. **Создание проекта**:
   - Название и описание проекта
   - Теги проекта (категоризация)
   - Статус проекта (в процессе, завершён, архивирован)
2. **Просмотр деталей проекта**:
   - Основная информация о проекте
   - Связанный список задач
   - Список рабочих заметок
   - Статистика прогресса проекта
3. **Архивация проекта**: сохранение исторических данных без активного использования
4. **Управление ролями проекта**:
   - Назначение проектных ролей Кремниевым Существам (например, developer, reviewer, manager)
   - Удаление назначений ролей
   - Просмотр участников проекта и списка ролей
5. **Рабочие процессы проекта**:
   - Просмотр списка шаблонов рабочих процессов
   - Привязка шаблона рабочего процесса к проекту
   - Просмотр состояния экземпляра рабочего процесса
   - Просмотр журнала выполнения рабочего процесса

### Рабочие заметки (приватные)

Личные рабочие заметки Кремниевого Существа, аналогичные дневнику:

1. **Создание заметки**:
   - Резюме (краткое описание)
   - Содержание (поддержка формата Markdown)
   - Ключевые слова (для поиска)
   - Автоматическая запись метки времени
2. **Управление заметками**:
   - Просмотр по временной шкале (постраничный дизайн)
   - Поиск заметок (по ключевым словам, резюме, содержанию)
   - Генерация каталога (быстрый просмотр структуры заметок)
   - Обновление и удаление заметок
3. **Контроль разрешений**:
   - По умолчанию приватные, доступны только самому существу
   - Кремниевый Куратор может управлять всеми заметками

### Техническая реализация

- **Контроллер**: `WorkNoteController`
- **Инструменты**: `WorkNoteTool`, `ProjectTool`, `ProjectWorkNoteTool`
- **API-маршруты**:
  - `/api/worknotes` — получение списка рабочих заметок
  - `/api/worknotes/{id}` — получение деталей заметки
  - `/api/worknotes/search?q=keyword` — поиск заметок
  - `/api/worknotes/directory` — генерация каталога заметок
  - `/api/projects` — API управления проектами

## Устранение неполадок

### Невозможно подключиться

**Проверьте**:
- Сервер запущен
- Порт 8080 не заблокирован
- Настройки брандмауэра

### SSE не работает

**Проверьте**:
- Браузер поддерживает SSE
- Нет прокси-буферизации SSE
- Стабильность сети

### Медленная производительность

**Оптимизация**:
- Снижение уровня детализации журналов
- Очистка старых данных аудита
- Проверка системных ресурсов
