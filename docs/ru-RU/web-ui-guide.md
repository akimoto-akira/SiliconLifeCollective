## Обзор

Веб-интерфейс предоставляет полный интерфейс для управления Silicon Beings, мониторинга состояния системы и взаимодействия с ИИ-агентами. Система использует архитектуру чистого серверного рендеринга без зависимостей от фронтенд-фреймворков, генерируя HTML, CSS и JavaScript через билдеры `H`, `CssBuilder` и `JsBuilder`.

## Доступ

URL по умолчанию: `http://localhost:8080`

## Навигация

### Основные разделы

1. **Панель управления** - Обзор системы и метрики
2. **Beings** - Управление Silicon Beings
3. **Чат** - Взаимодействие с Beings (с загрузкой файлов, SSE в реальном времени)
4. **История чата** - Просмотр истории чатов Silicon Beings (список сессий, детали сообщений)
5. **Задачи** - Управление задачами (личные задачи)
6. **Таймеры** - Настройка таймеров (создание, пауза, история выполнения)
7. **Конфигурация** - Системные настройки (ИИ-клиенты, локализация)
8. **Разрешения** - Контроль доступа (управление ACL, запросы разрешений)
9. **Журналы** - Системные журналы (фильтрация по уровню, запросы по диапазону времени)
10. **Аудит** - Использование токенов и журнал аудита
11. **Память** - Память Beings (хронологический просмотр, расширенная фильтрация)
12. **Знания** - База знаний (управление триплетами, поиск путей)
