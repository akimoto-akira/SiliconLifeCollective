## Обзор

Безопасность Silicon Life Collective основана на модели **многоуровневой защиты в глубину**. Фундаментальный принцип: **Все операции ввода-вывода должны проходить через исполнители**, исполнители применяют проверки разрешений перед выполнением.

```
Вызов инструмента → Исполнитель → PermissionManager → Кэш частоты → Обратный вызов → (Куратор→AskUser / НеКуратор→GlobalACL→Deny)
```

## Модель разрешений

### Типы разрешений

| Тип | Описание |
|------|-------------|
| `NetworkAccess` | Исходящие HTTP/HTTPS запросы |
| `CommandLine` | Выполнение команд оболочки |
| `FileAccess` | Операции с файлами и каталогами |
| `Function` | Вызовы чувствительных функций |
| `DataAccess` | Доступ к системным или пользовательским данным |
