## 概述

Web UI 提供了一个全面的界面，用于管理硅基生命体、监控系统状态和与 AI 智能体交互。系统采用纯服务端渲染架构，零前端框架依赖，通过 `H`、`CssBuilder` 和 `JsBuilder` 构建器生成 HTML、CSS 和 JavaScript。

## 访问

默认 URL：`http://localhost:8080`

## 配置

### AI 客户端

配置 AI 后端（13 种客户端）：
- Ollama（本地）
- 阿里云百炼 DashScope（云端）
- 字节火山引擎 Ark（云端）
- 牧马人推理引擎 Herdsman（本地/云端，无需认证）
- 美团 LongCat（云端）
- 七牛云 AI（云端）
- DeepSeek（云端）
- 智谱 GLM（云端）
- 月之暗面 Kimi（云端）
- 硅基流动 SiliconFlow（云端）
- MiniMax（云端）
- 百度千帆 ERNIE（云端）
- 腾讯混元（云端）

每个客户端的配置表单由各客户端工厂动态提供（API 密钥、端点、模型下拉列表等），并有对应的帮助文档（可在配置页直接跳转）。

### IM 平台（多实例）

IM 平台配置支持多实例架构，可同时启用多个平台：

1. 点击**添加平台**，选择平台类型：
   - **Web UI**（内置，默认启用）
   - **飞书**（支持手动配置和 OAuth 一键授权）
   - **企业微信**（手动配置）
   - **钉钉**（手动配置，支持 Stream / HTTP 两种事件模式）
2. 按动态表单填写平台字段（必填项带星号，密钥字段为密码框）
3. 每个实例可独立启用/禁用、删除

**密钥环境变量**：配置值支持 `${ENV_VAR}` 占位符（如 `"${FEISHU_APP_SECRET}"`），运行时从环境变量解析，明文密钥不会写入 config.json。

**OAuth 授权向导**（飞书）：保存 appId/appSecret 后，配置页出现行内授权区，点击**授权**按钮会打开系统浏览器跳转飞书授权页；完成授权后令牌自动写回配置，页面通过 SSE 实时显示授权状态（成功/失败/超时），无需手动复制粘贴。

### MCP 服务器

MCP 服务器列表在配置页中集中管理（数组编辑器）：每行一个服务器（ID、名称、传输方式 stdio/http、命令或端点、启用状态），支持行内**添加**和**删除**。保存后服务器立即连接，其工具自动注入到硅基生命体。详见下文 [MCP 管理](#mcp-管理) 章节。

### 存储设置

- Default 版本：基础路径、时间索引、清理策略
- Fast 版本：SpeedyPack 存储引擎配置、.spk 文件管理、自动压缩设置

## 技能管理

### 功能概述

技能（Skill）是"工具编排 + 提示词模板"的可复用能力单元。技能管理页面（`/skill?beingId={id}`）为每个硅基生命体提供技能的可视化管理。

### 页面布局

- **左侧技能列表**：卡片式展示（标题、`版本 · 来源 · 触发模式` 徽章、描述）
- **右侧编辑器**：Markdown 编辑器（YAML 前置元数据 + 提示词正文）
- **顶部统计**：技能总数 / 自定义技能数 / 配额上限（如 `5 / 2 / 50`）

### 工具栏操作

- **新建**：载入 Markdown 技能模板
- **导入 .md / 导入 .json**：从本地文件导入技能
- **刷新**：重新加载技能列表

### 技能卡片操作

每个技能卡片提供 5 个操作：

| 操作 | 说明 |
|------|------|
| 编辑 | 在右侧编辑器中打开 Markdown，可保存（upsert） |
| 测试 | 输入参数 JSON，立即执行一次技能并查看结果 |
| 导出 JSON | 下载 `{id}.json` |
| 导出 Markdown | 下载 `{id}.md` |
| 删除 | 删除技能（含持久化文件） |

### 编写技能

技能以 Markdown 编写，YAML 前置元数据声明 id、描述、参数 schema、工具白名单、触发模式等；正文为提示词模板（支持 `{param}` 占位符）。只写正文（省略 YAML）也可以——保存时 AI 会自动补全缺失的元数据，且用户提供的字段永不被覆盖。

```markdown
---
id: daily_news_digest
description: 搜索今日科技新闻并生成摘要
tool_whitelist: [network, work_note]
trigger_mode: Auto
metadata:
  schedule: "0 9 * * *"
---

请使用 network 工具搜索 {topic} 的最新新闻，生成 500 字摘要并保存到工作笔记。
```

### 技术实现

- **控制器**：`SkillController`（页面 + 10 个 API 端点）
- **核心**：`SkillManager`（注册/执行/热重载）、`SkillMetadataCompleter`（AI 元数据补全）
- **热重载**：生命体每 30 秒检测 `skills/` 目录变更，Web UI 保存后无需重启
- **版本归档**：每次更新自动归档到 `skills/archive/{id}/{version}.md`

## MCP 管理

### 功能概述

MCP（Model Context Protocol，模型上下文协议）管理页面（`/mcp`）用于管理外部 MCP 服务器连接。连接后，服务器提供的工具会以 `mcp_{服务器ID}_{工具名}` 的形式自动注入到所有硅基生命体。

### 服务器列表

显示每个服务器的：ID、名称、传输方式（stdio/http）、连接状态（connected/disconnected/connecting/error）、启用状态、工具数量、最近错误。

### 管理操作

| 操作 | 说明 |
|------|------|
| 添加服务器 | 填写 ID（小写字母/数字/下划线）、名称、传输方式；stdio 需命令和参数，http 需端点 URL |
| 启用/禁用 | 行内开关，禁用后工具从所有生命体注销 |
| 重连 | 断开并重连，刷新工具列表 |
| 删除 | 移除服务器配置及其所有工具 |
| 查看工具 | 展开服务器，列出工具名（带前缀）、描述、参数 schema |
| 测试工具 | 直接调用某个 MCP 工具验证连通性（无需 AI 参与） |

### 添加 stdio 服务器示例

```json
{
  "id": "filesystem",
  "name": "Filesystem",
  "transport": "stdio",
  "command": "npx",
  "arguments": ["-y", "@modelcontextprotocol/server-filesystem", "/data"],
  "enabled": true
}
```

### 安全机制

- 服务器的添加/删除/启停只能由用户通过 Web UI 完成，AI 无法修改服务器列表（`mcp` 工具仅提供只读查询）
- MCP 包装工具在工具权限矩阵中以单一 `execute` 动作呈现，可按生命体/项目逐个禁用
- 全局开关 `McpEnabled` 可一键关闭整个 MCP 集成

## 故障排除

### 无法连接

**检查**：
- 服务器正在运行
- 端口 8080 未被阻止
- 防火墙设置

### SSE 不工作

**检查**：
- 浏览器支持 SSE
- 无代理缓冲 SSE
- 网络稳定性

### 性能慢

**优化**：
- 降低日志详细程度
- 清理旧审计数据
- 检查系统资源
